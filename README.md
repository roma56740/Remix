# RAMIX MUSIC

FastAPI-сайт музыкальной дистрибуции и Telegram-бот работают в одном процессе. Бот запускается вместе с FastAPI через lifespan приложения; если `BOT_TOKEN` не указан, сайт продолжает работать без бота.

## Локальный запуск

1. Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. Откройте `.env` и заполните минимум:

```env
SESSION_SECRET=длинная-случайная-строка
ADMIN_EMAILS=ваш@email.ru
BOT_TOKEN=токен_из_BotFather
BOT_USERNAME=username_бота_без_символа_@
ADMIN_TELEGRAM_IDS=ваш_telegram_id
SITE_URL=http://127.0.0.1:8000
```

Несколько Telegram ID администратора указываются через запятую.

3. Запустите сайт и бота одной командой:

```powershell
python run.py
```

Сайт: `http://127.0.0.1:8000`  
Проверка: `http://127.0.0.1:8000/health`

## Telegram

Пользователь открывает бота, нажимает «Подключить аккаунт», вводит логин или email, затем пароль. Сообщение с паролем удаляется после проверки, пароль в Telegram-таблицах не сохраняется.

После подключения доступны:

- уведомления о модерации релиза;
- уведомления о питчинге;
- ответы поддержки;
- изменения баланса и статуса выплат;
- список релизов и уведомлений;
- создание заявки на выплату через Telegram.

Администратор получает уведомления о новых регистрациях, релизах, обращениях поддержки, питчинге и выплатах.

## Railway

1. Загрузите проект в GitHub.
2. Создайте сервис из репозитория в Railway.
3. Railway использует `python run.py` из `railway.toml`.
4. Добавьте переменные из `.env.example` в Variables.
5. Укажите публичный домен в `SITE_URL`, например `https://your-service.up.railway.app`.
6. Добавьте Railway Volume и смонтируйте его в `/data`.
7. Установите `DATA_DIR=/data`.
8. Используйте одну реплику сервиса: Telegram long polling должен выполняться только одним экземпляром.

База SQLite, обложки, аудио и XLSX-импорты будут храниться внутри `/data`.

## Важные переменные

| Переменная | Назначение |
|---|---|
| `SESSION_SECRET` | Подпись cookie-сессии |
| `ADMIN_EMAILS` | Email администраторов через запятую |
| `BOT_TOKEN` | Токен Telegram-бота |
| `BOT_USERNAME` | Username бота без `@` |
| `ADMIN_TELEGRAM_IDS` | Telegram ID администраторов через запятую |
| `SITE_URL` | Публичный адрес сайта для кнопок в Telegram |
| `DATA_DIR` | Каталог SQLite и пользовательских файлов |
| `COOKIE_HTTPS_ONLY` | В production установите `true` |

Файл `.env` уже находится в `.gitignore` и не должен попадать в публичный Git-репозиторий.
